# 레이저 소재 가이드 (Laser Material Guide)

레이저 조각기 고객이 가장 많이 묻는 **"이 소재는 파워 몇 %, 속도 얼마로 하나요?"** 에
장비 출력에 맞춰 답해 주고, 그 자리에서 **재료를 주문**할 수 있게 만든 설치형 웹앱(PWA)입니다.

설치가 필요 없는 웹 주소 하나로 배포되고, 홈 화면에 추가하면 앱처럼 실행되며
**인터넷이 끊긴 작업장에서도** 설정값을 볼 수 있습니다. (앱스토어 심사·수수료 없음)

---

## 1. 무엇을 할 수 있나

| 화면 | 기능 |
|---|---|
| **설정** | 소재 24종 x 절단/외곽선/조각 x 장비 12종 프리셋(또는 직접 입력)의 출력%·속도·패스 계산, 두께별 요약표 |
| **재료** | 상품 목록·장바구니·주문서 작성(카톡 공유 / 메일 / 복사 / 서버 전송) |
| **테스트** | 파워 x 속도 테스트 그리드 G코드 생성 (GRBL·LightBurn·LaserGRBL) |
| **기록** | 실제로 잘 나온 값을 기기에 저장, JSON 내보내기 |
| **안전** | 가공 금지 소재 8종과 이유, 대체 소재 추천, 작업 전 점검 목록 |

판매로 이어지는 동선이 앱 안에 들어 있습니다.

* 설정 계산 결과 → **"○○ 구매하기"** 버튼 → 해당 상품 바로 담기
* 다이오드로 불가능한 소재(예: 투명 아크릴) → **대체 소재 추천** → 상점 연결
* 금지 소재 안내 → **대체 소재 보기** → 상점 연결
* 주문서에 고객의 **보유 장비 정보**가 함께 담겨, 다음 소재 추천에 활용할 수 있습니다.

## 2. 실행

```bash
cd laser-app
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

빌드 도구·서버·데이터베이스가 필요 없는 순수 정적 파일입니다.

## 3. 배포 (고객에게 나눠줄 주소 만들기)

* **GitHub Pages** — 저장소 Settings → Pages → 브랜치와 `/laser-app` 폴더 선택
* **Netlify / Vercel** — `laser-app` 폴더를 그대로 끌어다 놓기
* **직접 운영하는 웹서버** — 폴더를 통째로 업로드

> HTTPS(또는 localhost)에서만 "홈 화면에 설치"와 오프라인 캐시가 동작합니다.

고객 안내 문구 예시:
> 주소를 열고 → (아이폰) 공유 → 홈 화면에 추가 / (안드로이드) 메뉴 → 앱 설치

## 4. 내 가게에 맞게 고치기

| 파일 | 내용 |
|---|---|
| `js/config.js` | 상호·연락처·카카오채널·계좌·배송비·무료배송 기준·주문 수신 URL |
| `js/shop.js` | 판매 상품, 규격, 가격, 재고 상태 |
| `js/materials.js` | 소재별 계수, 두께 목록, 팁·주의사항, 금지 소재 |
| `icons/`, `tools/make_icons.py` | 앱 아이콘 (`python3 tools/make_icons.py` 로 재생성) |

`js/shop.js` 의 상품에 `materialId` 를 채워두면 설정 화면의 구매 버튼과 자동으로 연결됩니다.

주문을 서버로 받고 싶다면 `config.js` 의 `orderEndpoint` 에 URL을 넣으세요.
비워두면 카카오톡 공유 · 메일 · 클립보드 복사로 주문서가 전달됩니다.
(구글 폼, 스프레드시트 Apps Script 웹앱 URL 등을 그대로 쓸 수 있습니다.)

파일을 수정한 뒤에는 `sw.js` 의 `CACHE` 버전 문자열을 올려야
이미 설치한 고객의 기기에 새 내용이 반영됩니다.

## 5. 계산 방식

표에서 값을 찾아 보여주는 방식이 아니라, **에너지 기준으로 환산**합니다.
그래서 5W 다이오드부터 130W CO2까지 같은 데이터로 답을 낼 수 있습니다.

```
유효 출력   P [W]     = 장비 광출력 x 출력%
절단 선에너지 E [J/mm] = k x 두께^1.15 x 장비계수
절단 속도    v [mm/s]  = 패스수 x P / E
조각 면에너지 D [J/mm²] = density x 장비계수
조각 속도    v [mm/s]  = P / (D x 라인간격),  라인간격 = 25.4 / DPI
```

* 계산된 속도가 장비 최고 속도를 넘으면 → 출력을 낮춥니다.
* 너무 느리면 → 패스를 나눕니다. 패스 한도를 넘으면 **"이 장비로는 무리"** 라고 알려주고
  현실적인 절단 한계 두께를 함께 표시합니다.
* 장비계수가 `null` 인 조합(예: 다이오드 + 투명 아크릴, 파이버 + 목재)은 불가로 안내하고
  대체 소재를 추천합니다.
* CO2 튜브 수명(최대 80%), 최소 방전 출력(10%) 같은 장비별 제약도 반영합니다.

`k`, `density` 는 CO2 실측 설정값(예: 60W · 3mm 자작합판 · 70% · 20mm/s)에서 역산한 계수입니다.
**표시값은 시작값입니다.** 렌즈·초점·에어어시스트·소재 편차에 따라 ±30% 차이가 날 수 있어,
앱 안에서 바로 테스트 그리드 G코드를 만들어 검증하도록 안내합니다.

## 6. 테스트

```bash
node --test laser-app/tests/engine.test.mjs
```

계산 범위·장비 한계·데이터 무결성·상품 연결·G코드 문법을 검사합니다 (15개).

## 7. 파일 구성

```
laser-app/
├── index.html              앱 껍데기
├── manifest.webmanifest    설치 정보(이름·아이콘·시작 주소)
├── sw.js                   오프라인 캐시
├── css/app.css
├── js/
│   ├── config.js           판매자 설정  ← 먼저 고치세요
│   ├── materials.js        소재 데이터베이스
│   ├── shop.js             상품·가격
│   ├── engine.js           계산 엔진
│   ├── store.js            로컬 저장(장비·장바구니·기록)
│   ├── testgrid.js         테스트 그리드 G코드 생성
│   └── app.js              화면 로직
├── icons/                  앱 아이콘
├── tools/make_icons.py     아이콘 생성기(외부 라이브러리 없음)
└── tests/engine.test.mjs   계산 엔진 테스트
```

## 8. 안전 고지

이 앱의 값은 참고용 시작값이며, 가공 결과와 안전은 사용자 책임입니다.
PVC 등 금지 소재는 **안전** 탭에서 이유와 함께 확인하세요.
