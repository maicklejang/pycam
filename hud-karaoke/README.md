# HUD 노래방

차량 HUD(앞유리 반사)로 가사를 보는 노래방 앱입니다.
휴대폰을 대시보드에 눕혀 두면 앞유리에 가사가 떠오르고, 반사되어도 글자가
바로 읽히도록 화면을 좌우로 뒤집어 그립니다.

빌드 도구도 서버도 필요 없는 정적 웹앱이고, 설치하면 네트워크 없이 동작합니다.

```
hud-karaoke/
├── index.html              화면 구성
├── css/hud.css             HUD 스타일
├── js/
│   ├── main.js             전체 동작 연결
│   ├── lrc.js              LRC 파서 · 진행률 계산 (순수 함수, 테스트 대상)
│   ├── clock.js            재생 시계 (음원 재생 / 외부 오디오용 스톱워치)
│   ├── hudview.js          가사 렌더링 · 반전 · 색상
│   ├── library.js          곡 보관함 (IndexedDB)
│   ├── settings.js         설정 저장 (localStorage)
│   └── safety.js           화면 켜둠 · 전체화면 · 주행 잠금
├── songs/demo.lrc          데모 가사 (음원 없이 동작)
├── assets/make_icons.py    PWA 아이콘 생성 스크립트
├── sw.js, manifest.webmanifest   오프라인 설치용
├── build_standalone.py     전체를 한 파일로 합치는 빌드
├── standalone.html         빌드 결과 — 휴대폰에 그냥 옮겨 열면 됨
└── tests/lrc.test.mjs      단위 테스트
```

## 휴대폰에서 바로 테스트

`standalone.html` 한 파일이면 서버도 네트워크도 필요 없습니다. 메일·메신저·클라우드
드라이브 등 아무 방법으로 휴대폰에 옮긴 뒤 파일 앱에서 열면 그대로 동작합니다.
가사·설정·보관함까지 전부 이 한 파일 안에서 돌아갑니다.

`hud-karaoke/`의 소스를 고쳤다면 다시 만들어 주세요.

```sh
cd hud-karaoke
python3 build_standalone.py        # -> standalone.html
```

빌드 스크립트는 CSS와 모듈, 데모 가사를 한 파일로 합칩니다. 모듈 간 최상위 이름이
겹치면 빌드를 실패시키므로, 조용히 깨진 번들이 나오지 않습니다.

단, 단일 파일에는 서비스워커가 없어 **홈 화면 설치와 화면 항상 켜기(Wake Lock)는
동작하지 않습니다**. 실제 차량에서 상시로 쓰려면 아래 방법으로 올려서 쓰세요.

## 실행 (전체 기능)

`index.html`을 `file://`로 열면 동작하지 않습니다(ES 모듈 제약). 정적 서버로 여세요.

```sh
cd hud-karaoke
python3 -m http.server 8099
# 휴대폰에서 http://<PC의 IP>:8099 접속
```

GitHub Pages로 올리면 HTTPS라서 홈 화면 설치·오프라인·Wake Lock까지 모두 됩니다.
저장소 **Settings → Pages**에서 Source를 이 브랜치, 폴더를 `/ (root)`로 지정한 뒤
`https://<사용자>.github.io/pycam/hud-karaoke/` 로 접속하면 됩니다.

휴대폰에서 **홈 화면에 추가**하면 전체화면 앱으로 실행되고, 앱 껍데기 전체가
캐시되어 터널·지하주차장처럼 신호가 없는 곳에서도 그대로 열립니다.

> 서비스워커와 화면 항상 켜기(Wake Lock)는 `https://` 또는 `localhost`에서만
> 동작합니다. 집 안에서 쓸 때는 휴대폰을 USB로 연결해 포트 포워딩하거나,
> 아무 정적 호스팅에 올려 두는 쪽이 편합니다.

## 차에서 쓰는 법

1. 휴대폰을 계기판과 앞유리 사이에 **화면이 하늘을 향하도록** 눕힙니다.
2. **좌우 반전**을 켭니다(기본값). 앞유리에 반사된 글자가 바로 읽힙니다.
3. 화면 밝기를 최대로 올리고 실내등을 끕니다. 낮에는 잘 보이지 않는 것이 정상이며,
   야간·터널에서 가장 선명합니다.
4. 이중상(고스트)이 거슬리면 HUD 반사필름을 붙이거나, 앱의 **글로우**를 끕니다.
5. 미끄럼 방지 패드 위에 올려 두세요. 급제동 시 휴대폰이 날아갑니다.

색상은 시안 → 그린 → 앰버 → 화이트 순으로 반사가 밝습니다. 배경은 항상 순수
검정이라 앞유리에는 글자만 떠오릅니다.

## 음원과 가사

| 상황 | 방법 |
| --- | --- |
| 음원 + `.lrc` | 두 파일을 모두 선택 → 글자가 한 글자씩 채워집니다 |
| 음원만 있음 | `.txt` 가사를 넣고 **탭 싱크**로 직접 타이밍을 찍어 `.lrc`로 내보냅니다 |
| 차량 오디오·라디오로 재생 | 음원 없이 가사만 불러오는 **외부 오디오 모드**. 첫 소절에 맞춰 재생을 누르고 **가사 ±0.3s**로 미세 조정 |

지원 형식은 일반 LRC(`[01:23.45]가사`), 한 줄에 여러 시간표(후렴 반복),
글자 단위 확장 LRC(`<01:23.45>`), `[ti:] [ar:] [offset:]` 태그, 그리고 타이밍이
전혀 없는 일반 텍스트입니다.

곡은 **기기 안 IndexedDB에만** 저장됩니다. 어디로도 업로드하지 않으며 서버가
없습니다.

## 주행 중 안전

- **주행 잠금**: 화면 전체를 덮어 터치를 삼킵니다. 해제는 길게 누르기(1.2초)로만
  가능해서 노면 충격이나 옷깃에 스쳐도 곡이 넘어가지 않습니다.
  재생 시 자동으로 걸리게 설정할 수 있습니다(기본 8초 무조작).
- **화면 항상 켜기**: Wake Lock으로 화면이 꺼지지 않습니다.
- 재생 중에는 조작 버튼이 자동으로 숨고, 화면을 한 번 두드리면 다시 나타납니다.

이 앱은 **정차 중에 설정하고 주행 중에는 보기만** 하는 것을 전제로 합니다.
곡 선택·탭 싱크·싱크 조정은 정차 중에 하세요. HUD 반사가 전방 시야를 가리지
않도록 위치를 잡고, 차량 내 화면 표시에 관한 지역 법규를 확인하시기 바랍니다.

## 단축키 (PC에서 확인할 때)

| 키 | 동작 |
| --- | --- |
| `Space` | 재생 / 일시정지 |
| `←` `→` | 5초 뒤로 / 앞으로 |
| `↑` `↓` | 이전 줄 / 다음 줄 |
| `M` | 좌우 반전 |
| `F` | 전체화면 |
| `L` | 주행 잠금 |

## 테스트

파서와 진행률 계산은 의존성 없이 `node --test`로 검증합니다.

```sh
node --test 'hud-karaoke/tests/*.test.mjs'
```

아이콘을 다시 만들려면(외부 라이브러리 불필요):

```sh
cd hud-karaoke/assets && python3 make_icons.py
```

## 브라우저

Chrome·Edge·삼성 인터넷 등 크로미움 계열과 iOS Safari에서 동작합니다.
Wake Lock과 화면 방향 고정은 iOS Safari에서 지원되지 않으므로, iPhone에서는
기기 설정의 자동 잠금 시간을 늘려서 쓰세요.
