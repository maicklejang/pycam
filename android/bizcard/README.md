# 명함 스캐너 (BizCard Scanner)

핸드폰 카메라로 명함을 촬영하면 글자를 인식해서 **명함 사진과 주소록 항목을 함께
기기 연락처에 저장/갱신**하는 안드로이드 앱입니다.

- 온디바이스 OCR (Google ML Kit 한국어 모델, **네트워크 불필요**)
- 이름 / 회사 / 부서 / 직함 / 휴대폰 / 전화 / 팩스 / 이메일 / 웹사이트 / 주소 자동 분류
- 저장 전에 모든 항목을 화면에서 수정 가능
- **저장할 때 배경을 잘라내고 명함 영역만 보관** (자동 감지, 끌 수 있음)
- **명함 영역 직접 선택** — 자동 감지가 어긋나면 손으로 영역을 잡아 그 안에서만 인식
- **명함 목록 검색** — 이름·회사·번호·이메일·주소·인식 원문, 초성 검색 지원
- **연락처 그룹 선택** — 기기 주소록에 그룹이 있으면 저장할 그룹을 골라 넣기
- **내 명함 만들기·보내기** — 템플릿 6종으로 만들거나 **가지고 있는 종이 명함 사진을 그대로** 쓰기, vCard/이미지로 전송
- 같은 번호·이메일의 연락처가 이미 있으면 **덮어쓰지 않고 빠진 항목만 추가**
- 촬영한 명함 사진을 연락처 프로필 사진으로 등록 (기존 사진이 없을 때만)
- 스캔 기록 보관, vCard(.vcf) 공유

## 직접 빌드하기

필요한 것: JDK 17, Android SDK (compileSdk 34).

```bash
cd android/bizcard
./gradlew testDebugUnitTest    # 명함 파서 단위 테스트
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

`local.properties` 에 `sdk.dir=/path/to/Android/sdk` 를 적어 두거나 `ANDROID_HOME`
환경변수를 설정하면 됩니다.

### 릴리스 서명

`android/bizcard/keystore.properties` 를 만들면 `assembleRelease` 가 서명된 APK 를
만듭니다. (이 파일과 `.jks` 는 `.gitignore` 로 제외되어 있습니다.)

```properties
storeFile=release-keystore.jks
storePassword=****
keyAlias=bizcard
keyPassword=****
```

```bash
keytool -genkeypair -v -keystore release-keystore.jks -alias bizcard \
        -keyalg RSA -keysize 2048 -validity 10000
./gradlew assembleRelease
```

## 사용 흐름

1. **명함 촬영** — 안내선에 명함을 맞추고 촬영합니다. (갤러리의 기존 사진도 사용 가능)
2. **인식·확인** — OCR 결과가 항목별로 채워집니다. 틀린 값은 그 자리에서 고칩니다.
3. **연락처에 저장** — 주소록 권한을 허용하면 저장됩니다.
   - 같은 휴대폰/전화/이메일을 가진 연락처가 있으면 그 연락처에 **빠진 항목만 추가**합니다.
   - 없으면 새 연락처를 만듭니다.
   - 저장 시점에 사진에서 **명함 영역만 잘라내어** 보관하고, 그 이미지를 연락처 사진으로 씁니다.
   - 주소록에 그룹이 있으면 **그룹을 골라** 그 그룹에 넣을 수 있습니다.
4. **내 명함** — 목록 맨 위 `내 명함` 칸에서 자기 명함을 만들고 보냅니다.

### 명함 영역만 저장

OCR 이 찾아낸 글자 상자들을 군집으로 묶어 가장 큰 덩어리를 명함으로 보고, 여백을 더한 뒤
명함 비율(85.6:54)에 가깝게 넓혀 잘라냅니다. 배경에서 홀로 잡힌 글자는 군집에서 떨어져 나가
영역을 늘리지 않습니다. 글자가 사진 전체에 퍼져 있어 잘라낼 것이 없거나 감지 결과가
비정상적으로 작으면 원본을 그대로 둡니다.

확인 화면의 **"명함 영역만 저장"** 스위치로 미리보기를 보면서 켜고 끌 수 있습니다(기본 켜짐).
잘라내기는 저장할 때 한 번만 적용되며, 이미 잘린 명함은 다시 잘리지 않습니다.

### 검색

목록 위 검색창에 입력하면 이름·회사·부서·직함·휴대폰·전화·팩스·이메일·웹사이트·주소·메모와
**인식 원문**까지 훑어 걸러냅니다.

| 입력 | 동작 |
| --- | --- |
| `파이캠` | 부분 일치, 대소문자 무시 |
| `01012345678` 또는 `12345678` | 번호에서 구분자를 무시하고 일치 |
| `ㅎㄱㄷ` | 초성 검색 (→ 홍길동) |
| `홍길동 파이캠` | 공백으로 나눈 낱말을 모두 만족하는 명함만 |

### 명함 영역 직접 선택

확인 화면의 **"명함 영역 직접 선택"** 버튼을 누르면 사진 위에서 사각형을 손으로 잡을 수
있습니다. 모서리·변을 끌어 크기를 바꾸고 안쪽을 끌어 옮깁니다. `이 영역으로 인식` 을 누르면
**선택한 영역 안에서만** 글자를 다시 읽고, 저장할 때도 그 영역만 남깁니다.

자동 감지가 명함을 잘못 잡았거나, 한 사진에 명함이 여러 장 있어 한 장만 읽고 싶을 때
씁니다. `전체 선택` 을 누르고 확인하면 자동 감지로 돌아갑니다.

사각형 계산(모서리 잡기, 경계·최소 크기 제한, 화면↔이미지 좌표 변환)은 안드로이드에
의존하지 않는 `CropGeometry` 에 모아 두고 단위 테스트로 검증합니다.

### 연락처 그룹 선택

기기 주소록에 그룹이 있으면 확인 화면 아래에 **연락처 그룹** 줄이 생깁니다. `그룹 선택` 으로
여러 그룹을 고를 수 있고, 마지막에 고른 그룹은 기억해 두어 다음 저장 때 미리 선택됩니다.

- 연락처 한 개는 계정 한 곳에만 속하므로 **같은 계정의 그룹만** 함께 고를 수 있습니다.
  다른 계정의 그룹을 섞어 고르면 첫 번째 계정 것만 남기고 알려 줍니다.
- 새 연락처는 고른 그룹의 계정에 만들어집니다. 그룹을 고르지 않으면 기기 로컬에 저장됩니다.
- 이미 있는 연락처를 갱신할 때는 계정을 옮길 수 없으므로, **그 연락처와 같은 계정의 그룹만**
  추가됩니다. 이미 속한 그룹은 건드리지 않습니다.
- 저장 후 안내 문구에는 **실제로 적용된 그룹만** 표시됩니다.

읽기 권한이 없으면 그룹을 알 수 없습니다. `그룹 선택` 을 누르면 권한을 요청하고, 저장할 때
권한을 처음 허용한 경우에는 저장 직전에 그룹 선택 창을 한 번 띄웁니다.

## 내 명함 만들기·보내기

목록 화면 **맨 위의 `내 명함` 칸**(만들어 둔 명함의 모습과 이름이 함께 보입니다)이나
오른쪽 위 메뉴로 들어갑니다. 만드는 방법이 두 가지입니다.

### 템플릿으로 만들기

| 단계 | 내용 |
| --- | --- |
| 템플릿 | 세로 띠 / 가로 띠 / 가운데 정렬 / 좌우 분할 / 담백하게 / 색 가득 (6종) |
| 강조색 | 템플릿 기본색 + 6색. 템플릿을 바꾸면 그 템플릿 기본색으로 돌아갑니다 |
| 내용 | 이름·회사·부서·직함·한 줄 소개·휴대폰·전화·팩스·이메일·웹사이트·주소 |

입력하는 대로 위쪽 미리보기가 바뀌고, 템플릿 썸네일에도 **자기 내용이 그대로** 들어가
비교할 수 있습니다. 명함 그림은 표준 명함 비율(85.6:54)로 그려집니다.

### 명함 사진 사용

이미 가지고 있는 종이 명함을 그대로 쓰는 방법입니다. 세 곳에서 가져올 수 있습니다.

| 버튼 | 가져오는 곳 |
| --- | --- |
| `스캔한 명함에서 고르기` | 이 앱으로 이미 스캔해 둔 명함 목록에서 고릅니다 |
| `직접 촬영` | 카메라로 바로 찍습니다 |
| `갤러리` | 휴대폰에 있는 사진에서 고릅니다 |

- 어디서 가져오든 EXIF 회전을 적용하고 최대 2048px 로 줄여 `filesDir/my_card.jpg` 한 장으로
  보관합니다. 스캔 기록을 지워도 내 명함 사진은 남습니다.
- `스캔한 명함에서 고르기` 로 가져오면 그 명함에서 읽어 둔 이름·회사·번호 중
  **비어 있는 항목만** 채웁니다. 이미 입력해 둔 값은 건드리지 않습니다.
- 사진 모드에서도 아래 항목은 그대로 편집할 수 있습니다. vCard 로 보낼 때 쓰입니다.

### 보내기

**`내 명함 보내기`** 는 세 가지 중에서 고릅니다.

- `vCard(.vcf) 로 보내기` — 받는 쪽이 연락처로 바로 가져갈 수 있습니다. 항목이 하나도
  비어 있지 않아야 보낼 수 있습니다.
- `명함 이미지 로 보내기` — 템플릿 모드는 1024px 폭 PNG, 사진 모드는 가지고 있는
  사진(JPEG)을 다시 압축하지 않고 그대로 보냅니다.
- `vCard 와 이미지 함께 보내기`

내 명함 내용은 앱 설정(`SharedPreferences`)에, 사진은 앱 내부 저장소에 남습니다.
보내기를 누르면 그 시점 내용이 함께 저장됩니다. 보낼 파일은 `cacheDir/shared` 에 만들어
`FileProvider` 로 넘깁니다.

## 권한

| 권한 | 용도 |
| --- | --- |
| `CAMERA` | 명함 촬영 |
| `READ_CONTACTS` | 중복 연락처를 찾아 덮어쓰지 않기 위해 |
| `WRITE_CONTACTS` | 연락처 생성 / 항목 추가 |

명함 사진과 인식 결과는 앱 내부 저장소(`filesDir/cards`)에만 저장되며 외부로 전송되지
않습니다. OCR 모델은 APK 에 포함되어 오프라인에서 동작합니다.

## 한계

- 세로로 흐르거나 배경 문양이 강한 명함은 항목 분류가 어긋날 수 있습니다. 저장 전
  확인 화면에서 수정하세요.
- 항목 분류 규칙은 한국어/영문 명함을 기준으로 만들어졌습니다.
- 명함 영역 감지는 글자 위치를 근거로 하므로, 글자가 한쪽에 몰린 명함은 반대쪽 여백이
  덜 남을 수 있습니다. 미리보기를 보고 어긋나면 스위치를 꺼서 원본으로 저장하세요.
- 잘라내기는 파일을 덮어쓰므로 원본 사진은 남지 않습니다.
- 그룹은 기기 주소록에 이미 만들어져 있는 것만 고를 수 있습니다. 이 앱에서 그룹을 새로
  만들지는 않습니다. 또한 한 번에 한 계정의 그룹만 적용됩니다.
- 내 명함 템플릿은 글자만 배치합니다. 로고 넣기는 들어 있지 않습니다. 사진을 쓰려면
  `명함 사진 사용` 으로 종이 명함을 찍어 쓰세요.
- 내 명함 사진은 한 장만 보관합니다. 새로 고르면 이전 사진을 덮어씁니다.
