# docscan 웹앱 — 폰에 설치하는 문서 스캐너

폰 브라우저에서 열고 **홈 화면에 추가**하면 아이콘이 생기고, 앱처럼 전체 화면으로
실행되는 문서 스캐너입니다. 안드로이드와 아이폰 모두 되고, 앱스토어·설치 파일이
필요 없습니다.

- 카메라 미리보기에 **문서 외곽선을 실시간 표시**하고, 가만히 들고 있으면 자동 촬영
- 촬영은 미리보기 화면이 아니라 **카메라가 낼 수 있는 최대 해상도의 사진**으로
- 촬영한 뒤 **문서 영역을 손으로 직접 지정**(기본 동작) — 모서리를 끌어 맞추고,
  변의 손잡이를 끌어 **휜 변**까지 맞출 수 있습니다
- 기울기(원근) 보정 + **휜 페이지 평탄화** + 그림자 제거 + 5가지 색 모드
- 여러 장 촬영 후 **PDF 한 개로 저장/공유**
- **사진이 서버로 전송되지 않습니다.** 모든 처리는 폰 안에서 끝납니다
- 한 번 열어두면 **오프라인에서도 실행**됩니다

같은 알고리즘(검출·비율 복원·보정·PDF)을 쓰는 명령줄 버전은
[../README.md](../README.md)를 보세요. 브라우저에서는 OpenCV.js(WebAssembly)로
동작합니다.

## 폰에 설치하기

1. 폰 브라우저에서 배포된 주소(아래 "배포하기" 참고)를 엽니다. **반드시 `https://`**
   여야 카메라를 쓸 수 있습니다.
2. 설치합니다.
   - **안드로이드(Chrome)**: 주소창 옆 `앱 설치` 버튼 또는 메뉴 → `앱 설치`
     (앱 상단의 `앱 설치` 버튼을 눌러도 됩니다)
   - **아이폰(Safari)**: 공유 버튼 → `홈 화면에 추가`
3. 처음 실행하면 카메라 권한을 허용합니다.

설치하지 않고 브라우저 탭에서 그냥 써도 기능은 같습니다.

## 쓰는 법

| 조작 | 설명 |
| --- | --- |
| 가운데 큰 버튼 | 촬영 |
| `AUTO` | 자동 촬영 — 문서를 가만히 들고 있으면 스스로 찍습니다 |
| `영역 확인` | 촬영 후 영역 편집 화면을 띄울지 여부 (기본 켜짐) |
| 색 모드 칩 | 컬러 / 선명 / 회색 / 흑백 / 원본 |
| 왼쪽 아래 아이콘 | 촬영한 페이지 목록 (크게 보기·순서 변경·회전·저장·삭제) |
| `사진 불러오기` | 이미 찍어둔 사진을 스캔 |
| `PDF 저장` | 전체 페이지를 PDF 한 개로 저장하거나 공유 |

외곽선 색: **초록** = 잘 잡힘, **노랑** = 자동 촬영 직전, **주황** = 문서가 화면을
벗어남(뒤로 조금 물러나세요).

### 화질

작은 글씨가 뭉개지는 가장 큰 원인은 렌즈가 아니라 **픽셀 수**입니다. 미리보기 영상은
초당 30장을 그리려고 축소된 화면이라, 거기서 잘라낸 페이지는 글씨가 몇 픽셀밖에 안
됩니다. 그래서 이 앱은:

- 브라우저에 `ImageCapture`가 있으면(안드로이드 크롬 등) 셔터를 누를 때 **센서 원본
  해상도의 사진**을 따로 찍습니다. 보통 미리보기의 4~8배(8~12MP)입니다.
- 그 기능이 없으면(사파리) **영상 스트림 자체를 카메라 최대 해상도로** 올려서 찍습니다.
- 문서용 **연속 자동초점**을 켭니다.
- 촬영한 사진의 해상도는 **영역 편집 화면 위쪽에 표시**되므로 바로 확인할 수 있습니다.
- 결과 페이지는 **A4 300dpi(긴 변 3508픽셀)** 를 넘지 않게 맞춥니다. 그 이상은 더
  선명해지지 않으면서 PDF만 무거워지고 폰에서 느려집니다.

카메라 최대 해상도가 낮다고 앱이 알려주면(예: 1280×720), **폰 기본 카메라 앱으로 찍고
`사진 불러오기`로 가져오세요.** 웹에서 열 수 있는 해상도보다 항상 큽니다.

### 영역 편집 화면

촬영하거나 사진을 불러오면 편집 화면이 먼저 뜹니다(`영역 확인`을 끄면 자동 영역으로
바로 저장합니다). 자동 검출 결과가 미리 채워져 있으니 어긋난 곳만 고치면 됩니다.

| 조작 | 설명 |
| --- | --- |
| **초록 손잡이**(네 모서리) | 문서의 꼭짓점을 맞춥니다. 끌면 확대경이 떠서 정확히 맞출 수 있습니다 |
| **노랑 손잡이**(각 변 가운데) | 변을 곡선으로 휘게 합니다 — 책처럼 휜 페이지용 |
| `자동 감지` | 자동 검출 결과로 되돌립니다 |
| `전체` | 사진 전체를 영역으로 잡습니다 |
| `직선으로` | 휘어 놓은 변을 다시 직선으로 폅니다 |
| `평탄화` | 휜 페이지를 펴서 저장할지 여부 (기본 켜짐) |
| `취소` / `확인` | 이 장을 버리거나 저장합니다 |

`평탄화`가 켜져 있으면 손으로 대충 맞춘 영역이라도 앱이 밝기 경계를 따라 **실제 종이
가장자리를 다시 찾아 꼭짓점을 종이 위로 붙이고**, 종이가 멀어지며 눌린 만큼을 되돌린
뒤, 남은 왜곡은 글줄의 휘어짐을 보고 바로잡습니다(자세한 내용은
[../README.md](../README.md)). 평평한 페이지는 원근 보정만 하고 그대로 둡니다.
변을 **직접 휘게 만든 경우에는 그린 그대로** 씁니다.

### 페이지 목록

| 조작 | 설명 |
| --- | --- |
| **미리보기 누르기** | 페이지를 **전체 화면으로 크게** 봅니다 |
| `◀` `▶` | 페이지 **순서를 바꿉니다**. 바뀐 순서가 PDF에 그대로 들어갑니다 |
| `회전` `저장` `삭제` | 그 페이지만 돌리거나, 이미지로 저장하거나, 지웁니다 |

크게 보기 화면에서는 **두 손가락으로 벌리거나 두 번 두드려 확대**할 수 있고(최대 6배),
확대한 상태에서 끌어 옮기고, **좌우로 밀어 다음/이전 페이지**로 넘어갑니다. 글씨가
제대로 찍혔는지 PDF로 저장하기 전에 확인하는 용도입니다. 화면 아래 `회전`·`저장`·
`삭제`는 보고 있는 페이지에 바로 적용됩니다.

촬영한 페이지는 순서까지 폰 안(IndexedDB)에 저장되므로 실수로 새로고침해도 사라지지
않습니다.

## 배포하기 (GitHub Pages)

카메라는 HTTPS에서만 열리므로, 폰에서 쓰려면 어딘가에 올려야 합니다. 이 저장소에는
Pages 배포 워크플로가 들어 있습니다.

1. GitHub 저장소 → **Settings → Pages → Source** 를 **GitHub Actions** 로 바꿉니다.
   (이걸 해야 `github-pages` 환경이 생기고 배포가 가능해집니다.)
2. 변경 사항을 **기본 브랜치(master)** 에 반영합니다. Pages는 기본 브랜치에서만
   배포를 받으므로, 기능 브랜치 push로는 배포되지 않습니다(테스트만 돕니다).
   master에 들어오면 워크플로가 테스트를 돌리고 자동 배포합니다. Actions 탭에서
   `docscan web app` → `Run workflow` → **master 선택** 으로 직접 실행해도 됩니다.
3. 이 저장소의 Pages 사이트에는 STL/STEP/DXF 뷰어도 함께 올라갑니다. 저장소 하나당
   사이트는 하나뿐이라 배포 워크플로가 두 앱을 한 번에 올립니다.
   - `https://<사용자이름>.github.io/<저장소이름>/` → 뷰어
   - `https://<사용자이름>.github.io/<저장소이름>/docscan/` → 이 스캐너
   Actions 실행 화면의 `deploy` 잡에도 주소가 표시됩니다.

직접 다른 곳에 올린다면 `docscan/web/` 폴더 전체를 그대로 정적 호스팅하면 됩니다.
단, `vendor/opencv.js`가 없으면 앱이 CDN에서 내려받으므로, 완전히 자체 호스팅하려면
배포 전에 `./fetch-opencv.sh`를 실행해 넣어두세요.

## 로컬에서 실행

```bash
docscan/web/fetch-opencv.sh          # OpenCV.js(약 13MB) 준비
python3 -m http.server 8000          # 저장소 최상위에서
# 브라우저에서 http://localhost:8000/docscan/web/ 열기
```

`localhost`는 HTTPS가 아니어도 카메라를 쓸 수 있습니다. 같은 와이파이의 폰에서
`http://192.168.x.x:8000/...` 로 접속하면 **카메라는 막히고** 사진 불러오기만 됩니다.

## 테스트

```bash
python3 docscan/web/tests/make-fixtures.py   # 합성 문서 사진과 파이썬 기준 결과 생성
npm install playwright && npx playwright install chromium
node docscan/web/tests/run.mjs
```

테스트는 두 부분입니다.

- **모듈 테스트** — 기하·검출·보정·PDF·저장소. 검출 결과와 보정 결과를
  **파이썬 구현의 출력과 직접 비교**하므로 두 구현이 벌어지면 바로 드러납니다.
- **앱 테스트** — 가짜 카메라(합성 문서 영상)를 물려 실제 UI를 조작합니다: 촬영,
  영역 편집(모서리 끌기·변 휘기·취소), 색 모드 변경, 갤러리, 크게 보기(넘기기·확대),
  순서 변경, 회전, PDF 내보내기, 새로고침 후 순서까지 복원, 서비스 워커 캐시.

## 알아둘 점

- **iOS 16.4 미만**에서는 `CompressionStream`이 없어 흑백 페이지가 1비트 무손실
  대신 JPEG으로 들어갑니다(파일이 조금 커질 뿐 동작은 같습니다).
- 첫 실행 때 OpenCV.js(약 13MB, 압축 전송 시 더 작음)를 내려받습니다. 이후에는
  캐시에서 즉시 뜹니다.
- 센서 원본 사진을 찍는 기기에서는 셔터를 누른 뒤 처리까지 1~3초 걸립니다. 사진이
  커진 만큼 계산량도 늘어난 것으로, 대신 글씨가 살아 있습니다.
- 실시간 검출은 빠른 프로파일(마스크 3종, 400px)로 돌고, 촬영 순간에는 전체
  프로파일로 다시 검출해 최종 꼭짓점을 잡습니다.
